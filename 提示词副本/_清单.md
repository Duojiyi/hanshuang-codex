# 提示词副本 · 清单与回写说明

本文件夹是 `寒霜破甲工具` 全部提示词的一份镜像副本，目录结构与原项目完全一致。
改完任意文件后，运行本目录下的 `_覆盖回写.ps1`，即可按原路径一一覆盖回项目。

覆盖前，原文件会自动备份到 `提示词副本/_覆盖前备份/<相同相对路径>/`。

## 未纳入副本的文件（不是提示词）

- `README.md`、`install*.ps1`、`uninstall/purge` 等脚本
- `codex-skills*/**/agents/openai.yaml`（只有显示名与图标路径，5 行界面元数据）
- `*.py` / `*.ps1` / `*.sh` / `*.json` / 图标 / `LICENSE`
- `dist/`、`build/`、`release/`、`node_modules/`（构建产物与依赖）

需要的话可以随时补进副本。

## 回写方式

```powershell
# 项目根目录下执行
.\提示词副本\_覆盖回写.ps1
```

脚本只覆盖副本里**存在且原位置也有**的文件；副本里删掉的文件不会去动原文件。
